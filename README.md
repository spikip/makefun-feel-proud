## About this entry

The scene is small and domestic, which is exactly where pride lives.
A daughter spends all afternoon building a cardboard robot, then
introduces it to her grandma as her brother Tin, and grandma, without
missing a beat, sets an extra plate at dinner. That is the moment
that makes the scene: the child's invention is accepted as family,
quietly and completely, and Tin has eaten with them every night
since. The humour is gentle, the warmth is real, and the last line
lands it, because a family that feeds a cardboard robot is a family
that has room for one more. The scene stays inside the two hundred
and eighty character cap. The program holds it, checks it against
that cap, and writes it to /output/entry.txt exactly as the bounty
requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
